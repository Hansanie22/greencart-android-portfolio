Engineered for Enterprise Mobile E-Commerce

Designed with high-scale architecture, modular components, and native Android performance optimizations.

📅

Automated Grocery Subscriptions

Allows users to setup daily, weekly, or monthly automated recurring deliveries with customizable delivery time-slots and instant pause/resume capabilities.

💳

PayHere Payment Gateway

Seamless checkout flow supporting credit/debit card tokenization, direct bank transfers, and GreenPoints loyalty deduction with secure checksum verification.

🗺️

Google Maps Real-time Tracking

Fullscreen interactive GPS maps tracking delivery riders in real time with calculated ETA, waypoint polyline rendering, and direct driver calling.

💾

Room DB & Offline-First Sync

Local SQLite caching via Room Database ensuring blazing-fast screen rendering, offline cart access, and background synchronization via WorkManager.

🎁

"Shake to Win" Gamification

Built-in accelerometer motion sensor detection triggering instant interactive scratch cards, loyalty GreenPoints, and coupon discounts.

🔔

Firebase Cloud Messaging (FCM)

Deep-linked push notification handler keeping users updated on dispatch status, subscription renewal reminders, and flash deals.

System Architecture & Clean Patterns

Separation of concerns using Android Architecture Components (AAC), MVVM, and Repository pattern.

Mobile Layer Breakdown

  • 01. UI Layer: Single-Activity + Multi-Fragment navigation with Material 3 components and ViewBinding.
  • 02. ViewModel Layer: Encapsulates UI state, handles LiveData observers, and survives Android configuration changes.
  • 03. Data & Cache Layer: Room DAO persistence for cart & product catalogs with Retrofit2 REST synchronization.
  • 04. Background Jobs: Android WorkManager workers handling periodic token synchronization and offline queue syncing.

Relational Schema

Includes production-ready DDL tables for Users, Orders, Order Items, Recurring Subscriptions, and Loyalty Scratch Cards. 

CREATE TABLE subscriptions (
  id SERIAL PRIMARY KEY,
  user_id INT REFERENCES users(id),
  frequency_type VARCHAR(50), -- WEEKLY / MONTHLY
  status VARCHAR(30) DEFAULT 'ACTIVE',
  next_delivery_date DATE
);
